そうするとかなり違うモデルになる。むしろ**権力論というより進化論として見る**のが素直かもしれない。

重要なのは、「強い個体が弱い個体を支配する」ではなく、

**多様な個体群 → 環境変化 → 予測・適応 → 選択 → 資源の偏在 → 次の選択**

というループ。

ここで人間社会の面白いところは、生物進化と違って**淘汰される対象が人間そのものとは限らない**ことだと思う。企業、職業、技術、投資戦略、制度、文化、アイデア、組織形態など、人間が作った「戦略」が大量に並行して存在している。

電子機器以前にも当然これらは淘汰されていた。ただ、淘汰が遅かった。

ある商売のやり方が優れていると分かるまで10年かかる。ある制度が失敗だと分かるまで一世代かかる。ある経営者の判断が間違っていたと判明するまで会社が傾く必要がある。

ところが計算機は、ここをものすごく短縮した。

**観測 → 予測 → 実験 → 評価 → 資源再配分**

の周期が、数十年→数年→数か月→数日→リアルタイム、と縮んでいく。

すると「予測精度が高い人が金持ちになる」というより、

**環境に適応した戦略へ資本が移動する速度そのものが上がった**

と考えた方が一般的になる。

そしてここに多様性が効いてくる。

淘汰には、そもそも**選択肢の多様性が必要**だから。

100万人全員が同じ予測モデルを使っていたら、計算能力がどれだけ高くても探索空間は狭い。逆に100万人が違う仮説・価値観・戦略を試しているなら、その中から環境に適合するものが出現する確率が上がる。

つまり社会全体では、

**多様性 = 探索能力**

と見なせる。

一方で、

**予測能力 = 選択能力**

になる。

さらに資本主義がかなり特殊なのは、

**資本 = 選択結果を増幅する装置**

として機能するところ。

当たった企業には投資が集まり、利益が再投資され、人材が集まり、さらに実験できる。当たらなかった企業は資本を失って探索能力を失う。

だから資本主義をこのモデルで見ると、

**Variation → Prediction → Selection → Amplification**

という巨大な進化機構になる。

そしてAIが入ると、この全部が加速する。

生成AIはVariationを増やす。予測モデルはSelectionを改善する。Agentは実験コストを下げる。資本市場はAmplificationを行う。

ここで初めてかなり不穏な問題が出てくる。

**選択が速すぎると、多様性を破壊する可能性がある。**

たとえば10種類の経営戦略があって、本当は環境Aでは戦略1、環境Bでは戦略7が強いとする。

ところが現在の環境Aで戦略1が少し優れていることをAIが非常に高精度に検出すると、資本が猛烈な速度で戦略1へ集中する。

戦略2〜10は消える。

その後環境Bになったとき、本来必要だった戦略7がもう存在しない。

生態系でいう**単一栽培**に近い。

だから「予測精度が上がれば社会は効率化する」は半分しか正しくない。

短期的には、

**予測精度↑ → 淘汰精度↑ → 効率↑**

だけど、長期的には、

**淘汰速度↑ → 多様性↓ → 未知の環境への適応力↓**

になり得る。

ここで最初の「一部の人間にパワーが集中する」に戻ると、さらに面白い。

問題は富の集中そのものより、

**成功した少数の予測モデルによって社会全体のVariationが削られること**

なのかもしれない。

一人の天才が1000億円持っていること自体より、その人の判断が正しいために資本・人材・企業がそのモデルへ集中し、**社会全体がその人の予測モデルのコピーになっていくこと**の方が進化論的には危険。

**束になること自体が必ずしも良くない。**

「誰がどれだけ資本を持つか」

**「未来について何種類の異なる仮説が、生き残って試され続けることを許されているか」**
