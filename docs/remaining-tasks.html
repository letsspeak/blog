デプロイ用 IAM アクセスキーのローテーション（期限: 2026-11-30）

P1

背景:GitHub Secrets の AWS_ACCESS_KEY_ID / AWS_SECRET_ACCESS_KEY は 2025-06-16 に設定されてから更新されていない。

手順:

  • IAM コンソールでデプロイ用ユーザーに新しいアクセスキーを発行する（古いキーはまだ残す）。
  • gh secret set AWS_ACCESS_KEY_ID -R letsspeak/blog と gh secret set AWS_SECRET_ACCESS_KEY -R letsspeak/blog で新しい値を登録する（値は標準入力から渡し、履歴やこのファイルに残さない）。
  • 空コミットか記事更新で Actions を 1 回走らせ、S3 同期と CloudFront 無効化が成功することを確認する。
  • 古いキーを「無効化」し、数日問題がなければ削除する。

確認:gh secret list -R letsspeak/blog の更新日時が新しくなっていること。

GitHub Support に旧コミットの purge を依頼する（任意）

P3

背景:2026-10-23 に AWS アカウント ID を含むファイルを履歴から除去して force push したが、旧コミットは GitHub 上で SHA 直打ちならガベージコレクションまで閲覧できる。ID は秘密情報ではないため必須ではない。
